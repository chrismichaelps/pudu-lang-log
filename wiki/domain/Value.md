# Value

A value is what a property holds ([[src/PuduLangLog|`Value`]]): a scalar (null, boolean, integer,
float, exact decimal, text, moment, duration, or bytes), a sequence, a structure with an optional
tag, or a dictionary. [[src/PuduLangLog/Value]] builds values and the `Capturable` trait turns
program types into them; [[domain/Capture]] limits them.
